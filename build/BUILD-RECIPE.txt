Reproduce HEATDEATH v2.1.0
==========================

1. Obtain the annotated tag v2.1.0 and independently pin its commit.
2. Use Node v26.7.0 on darwin/arm64.
3. Confirm npm 11.19.0, then run `npm ci --ignore-scripts`; verify the lockfile
   and registry attestations independently.
4. Run `npm run build:release` from a clean tagged worktree.
5. Check the SPDX SBOM and verify with
   `npm run verify-release -- --trusted-keys=/independent/key/dir`.

The JavaScript bundle is the primary auditable artifact. The SEA convenience
binary additionally embeds the exact Node runtime and is reproducible only for
the pinned Node build and platform. Node's Permission Model is a trusted-code
capability guard, not a sandbox for malicious code.

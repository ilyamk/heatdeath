## Стандарты и спецификации

| Термин | Значение | Подробнее |
|---|---|---|
| **BIP-32** | Иерархические детерминированные кошельки: из одного сида выводится дерево ключей. [Спецификация](https://github.com/bitcoin/bips/blob/master/bip-0032.mediawiki) | [ENTROPY.md](ENTROPY.md) |
| **BIP-39** | Стандарт мнемонической фразы: энтропия → слова → сид через PBKDF2. [Спецификация](https://github.com/bitcoin/bips/blob/master/bip-0039.mediawiki) | [ENTROPY.md](ENTROPY.md) |
| **BIP-44** | Структура путей деривации `m/44'/60'/0'/0/i`. [Спецификация](https://github.com/bitcoin/bips/blob/master/bip-0044.mediawiki) | [ENTROPY.md](ENTROPY.md) |
| **BIP-38** | Шифрование приватного ключа паролем. У нас не реализовано. [Спецификация](https://github.com/bitcoin/bips/blob/master/bip-0038.mediawiki) | [COMPARISON.md](COMPARISON.md) |
| **SLIP-39** | Разделение секрета по схеме Шамира на мнемонические доли со словарём из 1024 слов. [Спецификация](https://github.com/satoshilabs/slips/blob/master/slip-0039.md) | [THREAT-MODEL.md](THREAT-MODEL.md) |
| **EIP-55** | Контрольная сумма EVM-адреса, закодированная регистром букв. [Спецификация](https://eips.ethereum.org/EIPS/eip-55) | [VERIFY.md](VERIFY.md) |
| **ERC-4337** | Абстракция аккаунта в Ethereum; теоретический путь к постквантовым подписям транзакций. [Спецификация](https://eips.ethereum.org/EIPS/eip-4337) | [ENTROPY.md](ENTROPY.md) |
| **FIPS 204 / FIPS 205** | Стандарты NIST на постквантовые подписи: ML-DSA и SLH-DSA соответственно | [VERIFY.md](VERIFY.md) |
| **NIST SP 800-90B** | Методика оценки источников энтропии и health-тестов | [ENTROPY.md](ENTROPY.md) |
| **ISO/IEC 18004** | Стандарт QR-кода, по которому проверен встроенный кодер | [VERIFY.md](VERIFY.md) |
| **RFC 8018** | Определение PBKDF2 (PKCS #5 v2.1) | [ENTROPY.md](ENTROPY.md) |
| **RFC 8032** | Определение EdDSA, включая Ed25519 | [VERIFY.md](VERIFY.md) |

## Криптографические примитивы

| Термин | Значение | Подробнее |
|---|---|---|
| **PBKDF2** | Функция вывода ключа с растяжением по итерациям. В BIP-39 — 2048 итераций HMAC-SHA512, что **не** является защитой | [ENTROPY.md](ENTROPY.md) |
| **HMAC** | Код аутентификации сообщения на основе хеш-функции | [ENTROPY.md](ENTROPY.md) |
| **SHA-256 / SHA-512** | Хеш-функции семейства SHA-2 (FIPS 180-4) | [VERIFY.md](VERIFY.md) |
| **AES-GCM** | Блочный шифр в режиме с аутентификацией; используется хранилищем MetaMask | [METAMASK.md](METAMASK.md) |
| **secp256k1** | Эллиптическая кривая Bitcoin и Ethereum. Практический уровень стойкости — 128 бит | [ENTROPY.md](ENTROPY.md) |
| **keccak256** | Хеш-функция, из которой получается EVM-адрес (последние 20 байт) | [VERIFY.md](VERIFY.md) |
| **Ed25519** | Классическая подпись на кривой Эдвардса. Ломается алгоритмом Шора | [VERIFY.md](VERIFY.md) |
| **ML-DSA** | Постквантовая подпись на модульных решётках (FIPS 204), бывш. CRYSTALS-Dilithium | [ENTROPY.md](ENTROPY.md) |
| **SLH-DSA** | Постквантовая подпись только на хеш-функциях (FIPS 205), бывш. SPHINCS+. Самое консервативное допущение | [ENTROPY.md](ENTROPY.md) |
| **GF(256)** | Конечное поле из 256 элементов, арифметика SLIP-39. Порождающий элемент — умножение на `x+1`, **не** удвоение. Ошибка здесь была реальным багом, пойманным векторами | [THREAT-MODEL.md](THREAT-MODEL.md) |
| **Сеть Фейстеля** | Конструкция обратимого шифрования; в SLIP-39 — 4 раунда поверх PBKDF2 | [THREAT-MODEL.md](THREAT-MODEL.md) |
| **RS1024** | Контрольная сумма мнемонической доли SLIP-39 | [THREAT-MODEL.md](THREAT-MODEL.md) |
| **Схема Шамира** | Разделение секрета на `n` долей с порогом `k`: любые `k` восстанавливают, `k−1` не дают **ничего** — теоретико-информационно, а не вычислительно. [Оригинальная работа](https://dl.acm.org/doi/10.1145/359168.359176) | [THREAT-MODEL.md](THREAT-MODEL.md) |

## Ключи, сиды и адреса

| Термин | Значение | Подробнее |
|---|---|---|
| **Энтропия** | Мера непредсказуемости. Здесь — 256 бит, максимум для BIP-39, дающий 24 слова | [ENTROPY.md](ENTROPY.md) |
| **Сид (seed)** | 64 байта на выходе PBKDF2, корень всего дерева ключей BIP-32 | [ENTROPY.md](ENTROPY.md) |
| **Мнемоника** | 24 слова, кодирующие 256 бит энтропии плюс 8 бит контрольной суммы | [ENTROPY.md](ENTROPY.md) |
| **Passphrase («25-е слово»)** | Произвольный текст, попадающий в **соль** PBKDF2. Любая строка даёт валидный кошелёк — понятия «неверная passphrase» не существует | [ENTROPY.md](ENTROPY.md) |
| **Master fingerprint** | Четыре байта, идентифицирующие корневой ключ. Используется для сверки, от схемы деривации **не зависит** | [VERIFY.md](VERIFY.md) |
| **CKDpriv** | Функция вывода дочернего приватного ключа в BIP-32 | [ENTROPY.md](ENTROPY.md) |
| **Hardened-деривация** | Ветвь дерева, где индекс ≥ 2³¹. Утечка расширенного публичного ключа **не** раскрывает потомков | [ENTROPY.md](ENTROPY.md) |
| **xpub** | Расширенный публичный ключ. Его утечка при не-hardened схеме раскрывает публичные ключи всех адресов ветки | [ENTROPY.md](ENTROPY.md) |
| **ECDLP** | Задача дискретного логарифма на эллиптической кривой — то, на чём держится стойкость ключа | [ENTROPY.md](ENTROPY.md) |
| **`ecrecover`** | Операция EVM, восстанавливающая публичный ключ из подписи. Поэтому после первой отправки адрес теряет хеш-барьер | [ENTROPY.md](ENTROPY.md) |

## Случайность и её проверка

| Термин | Значение | Подробнее |
|---|---|---|
| **CSPRNG** | Криптографически стойкий генератор псевдослучайных чисел | [ENTROPY.md](ENTROPY.md) |
| **DRBG** | Детерминированный генератор случайных бит. `randomBytes` и `webcrypto` ведут в **один и тот же** DRBG внутри OpenSSL | [ENTROPY.md](ENTROPY.md) |
| **TRNG** | Аппаратный генератор на физическом источнике шума | [COMPARISON.md](COMPARISON.md) |
| **PRNG** | Генератор псевдослучайных чисел без криптографических гарантий. Подмена TRNG на PRNG — суть бага Coldcard | [COMPARISON.md](COMPARISON.md) |
| **Min-entropy** | Наихудшая оценка непредсказуемости: `−log₂` вероятности самого вероятного исхода. Именно она важна, а не энтропия Шеннона | [ENTROPY.md](ENTROPY.md) |
| **Health-тест** | Проверка источника энтропии в рантайме. Ловит **катастрофический** отказ, но не отличает хороший CSPRNG от плохого | [ENTROPY.md](ENTROPY.md) |
| **Monobit** | Тест баланса нулей и единиц; порог — отклонение более 5σ | [ENTROPY.md](ENTROPY.md) |
| **Repetition Count** | Тест на залипшие биты: 5 одинаковых байт подряд | [ENTROPY.md](ENTROPY.md) |
| **Adaptive Proportion** | Тест на вырожденное распределение: значение ≥13 раз в окне 512 | [ENTROPY.md](ENTROPY.md) |
| **χ² (хи-квадрат)** | Статистика согласия распределения. Для кубиков df = 5; предупреждение при p < 0.001 | [ENTROPY.md](ENTROPY.md) |
| **Попарное различие проб** | Сравнение проб двух путей ОС. Совпадение доказывает катастрофическое дублирование/заглушку; различие не доказывает независимость и отсутствие клонирования | [ENTROPY.md](ENTROPY.md) |
| **Diceware** | Метод генерации парольной фразы бросками кубика; одно слово ≈ 12.9 бита | [ENTROPY.md](ENTROPY.md) |

## Атаки и пределы

| Термин | Значение | Подробнее |
|---|---|---|
| **Предел Ландауэра** | Минимальная энергия на необратимое переключение бита: `kT·ln2` ≈ 2.87×10⁻²¹ Дж при 300 K. Досчитать до 2²⁵⁶ стоит ~3.3×10⁵⁶ Дж — около двух миллиардов Солнц. **К уровню 2¹²⁸ этот аргумент неприменим** | [ENTROPY.md](ENTROPY.md) |
| **Алгоритм Гровера** | Квантовый поиск с квадратичным ускорением: 2²⁵⁶ → 2¹²⁸. Плохо параллелится | [ENTROPY.md](ENTROPY.md) |
| **Алгоритм Шора** | Квантовый алгоритм, решающий ECDLP **полностью** за полиномиальное время. Длина мнемоники здесь не помогает | [ENTROPY.md](ENTROPY.md) |
| **Ро-метод Полларда** | Классическая атака на ECDLP со сложностью √n; отсюда 128-битный уровень secp256k1 | [ENTROPY.md](ENTROPY.md) |
| **Парадокс дней рождения** | Даёт 2⁸⁰ для нахождения *какой-нибудь* пары адресов. Прообраз **вашего** адреса — 2¹⁶⁰ | [ENTROPY.md](ENTROPY.md) |
| **Офлайн-перебор** | Атака на скопированный шифротекст без ограничения частоты попыток. Модель угроз хранилища MetaMask | [METAMASK.md](METAMASK.md) |
| **hashcat** | Инструмент перебора паролей на GPU; источник замеров в таблицах стойкости | [METAMASK.md](METAMASK.md) |
| **Атака паяльником** | Принуждение к выдаче секрета. Криптографией не закрывается | [THREAT-MODEL.md](THREAT-MODEL.md) |

## SLIP-39 и пороговое резервирование

| Термин | Значение | Подробнее |
|---|---|---|
| **Доля (share)** | Одна строка из набора. Её недостаточно для восстановления; из-за 4-байтового digest SLIP-39 буквальное свойство «ноль информации» неприменимо (для нашего 256-битного секрета остаётся около 224 бит) | [THREAT-MODEL.md](THREAT-MODEL.md) |
| **Порог (threshold)** | Минимальное число долей для восстановления. У нас по умолчанию 2 из 3 | [THREAT-MODEL.md](THREAT-MODEL.md) |
| **Допустимое подмножество** | Любой набор долей, удовлетворяющий порогу. Инструмент проверяет восстановление из **каждого** такого набора до печати | [THREAT-MODEL.md](THREAT-MODEL.md) |
| **Master secret** | Секрет, который делится. У нас это BIP-39 энтропия; Trezor читает его как BIP-32 seed — отсюда несовместимость | [THREAT-MODEL.md](THREAT-MODEL.md) |
| **Round-trip** | Проверка «разделили → собрали → совпало с исходным». Проверяет то, что ему дали, а не то, что вы хотели разделить | [THREAT-MODEL.md](THREAT-MODEL.md) |

## Рантайм и сборка

| Термин | Значение | Подробнее |
|---|---|---|
| **Модель разрешений Node** | `--permission` и флаги `--allow-*`: запрет сети, подпроцессов, воркеров, записи на диск на уровне рантайма. [Документация](https://nodejs.org/api/permissions.html) | [BUILD.md](BUILD.md) |
| **SEA** | Single Executable Application — механизм Node для сборки одного исполняемого файла. [Документация](https://nodejs.org/api/single-executable-applications.html) | [BUILD.md](BUILD.md) |
| **`mainFormat: "module"`** | Ключ SEA, без которого ESM-точка входа падает с `SyntaxError` | [BUILD.md](BUILD.md) |
| **`execArgvExtension: "none"`** | Ключ SEA, запрещающий `NODE_OPTIONS` **расширять** запечённые флаги. При дефолте `"env"` песочница снимается переменной окружения | [BUILD.md](BUILD.md) |
| **Воспроизводимая сборка** | Свойство: одни и те же исходники дают побайтово одинаковый артефакт. [Определение](https://reproducible-builds.org/docs/definition/) | [VERIFY.md](VERIFY.md) |
| **Lockfile / integrity** | Файл с точными версиями и хешами зависимостей; основа проверяемой установки | [THREAT-MODEL.md](THREAT-MODEL.md) |
| **postinstall** | Скрипт, исполняемый npm после установки пакета. Запрещается флагом `--ignore-scripts` | [THREAT-MODEL.md](THREAT-MODEL.md) |
| **`codesign`** | Утилита подписи кода в macOS. Ad-hoc подпись вшивает **имя файла** как идентификатор, поэтому переименование меняет хеш | [BUILD.md](BUILD.md) |
| **Gatekeeper / карантин** | Механизм macOS, молча убивающий скачанный неподписанный бинарник: exit 137, пустой вывод | [VERIFY.md](VERIFY.md) |
| **Нотаризация** | Проверка бинарника Apple за $99/год с привязкой к юрлицу. Не используется: противоречит псевдонимности подписей | [VERIFY.md](VERIFY.md) |

## Изоляция и доверенный путь

| Термин | Значение | Подробнее |
|---|---|---|
| **Namespace / cgroup** | Механизмы ядра Linux, изолирующие контейнеры **друг от друга**, но не от хоста | [THREAT-MODEL.md](THREAT-MODEL.md) |
| **`vmmap`** | Утилита macOS, отображающая карту памяти процесса. Работает **без root** для процессов вашего UID | [THREAT-MODEL.md](THREAT-MODEL.md) |
| **`mlock`** | Системный вызов, закрепляющий страницы в RAM. Node его не умеет, поэтому сид может уйти в swap | [THREAT-MODEL.md](THREAT-MODEL.md) |
| **Swap** | Выгрузка страниц памяти на диск. Под FileVault шифруется — смягчение, не гарантия | [THREAT-MODEL.md](THREAT-MODEL.md) |
| **Confidential computing** | Класс технологий, считающих гипервизор враждебным | [THREAT-MODEL.md](THREAT-MODEL.md) |
| **AMD SEV-SNP** | Шифрование памяти гостя ключами, недоступными гипервизору, плюс защита от подмены страниц | [THREAT-MODEL.md](THREAT-MODEL.md) |
| **Intel TDX** | Вынос гипервизора из доверенной вычислительной базы | [THREAT-MODEL.md](THREAT-MODEL.md) |
| **Secure Enclave** | Изолированный сопроцессор Apple. API для исполнения произвольного кода не предоставляется | [THREAT-MODEL.md](THREAT-MODEL.md) |
| **Проблема доверенного пути** | Даже идеальный анклав обязан **показать** вам 24 слова через фреймбуфер хоста. Это и есть точка утечки | [THREAT-MODEL.md](THREAT-MODEL.md) |

## Термины из разбора MetaMask

| Термин | Значение | Подробнее |
|---|---|---|
| **Vault (хранилище)** | Зашифрованный блок с мнемоникой на диске. Ключ выводится **только** из пароля и соли | [METAMASK.md](METAMASK.md) |
| **TOPRF** | Пороговая псевдослучайная функция; основа схемы соц-входа. Нами не аудирована | [METAMASK.md](METAMASK.md) |
| **CSP** | Content Security Policy — политика, запрещающая расширению исполнять удалённые скрипты | [METAMASK.md](METAMASK.md) |
| **LevelDB / IndexedDB** | Два места, где лежит шифротекст хранилища. Очистка одного не удаляет второе | [METAMASK.md](METAMASK.md) |
| **Cure53** | Аудиторская компания, проверявшая `@scure/bip39` в январе 2022 | [THREAT-MODEL.md](THREAT-MODEL.md) |
| **OWASP** | Организация, чья рекомендация 2023 года объясняет выбор 600 000 итераций PBKDF2 | [METAMASK.md](METAMASK.md) |
| **Instant Replay** | Функция iTerm2, записывающая содержимое сессии на диск даже без явного сохранения | [THREAT-MODEL.md](THREAT-MODEL.md) |
| **Accessibility API** | Интерфейс macOS, позволяющий процессу читать нажатия клавиш и содержимое чужих окон | [THREAT-MODEL.md](THREAT-MODEL.md) |
